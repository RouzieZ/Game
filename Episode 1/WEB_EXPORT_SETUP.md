**Вариант 1: Используя VS Code**
1. Щёлкните правой кнопкой на `Промпт.txt` в обозревателе → Переименовать на `Prompt.txt`
2. Закройте весь рабочий пространство VS Code
3. Вручную переименуйте папку `Episode 1` на `Episode_1` в Проводнике
4. Откройте проект заново в VS Code (он автоматически обновит внутренние пути)

**Вариант 2: Используя терминал (при закрытом проекте)**
```powershell
# После закрытия VS Code:
Move-Item -Path "d:\Игрульки\Game-main\Game\Episode 1" -Destination "d:\Игрульки\Game-main\Game\Episode_1"
Rename-Item -Path "d:\Игрульки\Game-main\Game\Episode_1\Промпт.txt" -NewName "Prompt.txt"
```

### Далее: процесс веб-экспорта

После завершения переименования:
1. Откройте редактор Godot
2. Перейдите в: Project → Export
3. Создайте новый HTML5-пресет (или обновите существующий)
4. Установите:
   - Режим Release
   - HTML5 шаблон: используйте пользовательский шаблон
   - Компрессия: включите deflate и brotli
5. Экспортируйте в желаемое место
6. Результат: `index.html` будет в корневой папке экспорта
